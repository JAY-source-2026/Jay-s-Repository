# 2026-10-23 — 설비 선택형 홈페이지 개편

현재 메인 화면은 전체 화면 자동 영상에서 **소개 문구 + 부분 3D 설비 뷰어**로 변경했다.
이 문서 아래의 이전 히어로·포스터 지침은 과거 작업 기록이다.

- 사람과 건물 전체를 순회하는 영상은 제거했다.
- 뷰어 아래에서 금속배관 / 비금속배관 / 덕트 / 스크린셔터를 선택하면 해당 모형으로 확대하여 한 번 재생한다.
- 금속배관·덕트: 내화채움재의 시공과 외곽 관통부 차단. 덕트 내부 방화댐퍼 동작과 구분한다.

- 스크린셔터: 감지 후 가이드레일을 따라 스크린이 하강한다.
- 전체 보기 / 다시 재생 / 키보드 방향키 / 모션 축소 / WebGL 미지원 설명 대체를 제공한다.
- 실제 인정 사양이나 시험 결과를 재현하는 시뮬레이션이 아닌 작동 원리 개념도다.

3D는 저장소의 Three.js를 사용하며 별도 빌드 과정이 없다. `company-site`에서 `python3 -m http.server 8000`으로 확인한다.

### 사진/영상 교체 방법 (파일만 넣고 한 줄 추가)
| 위치 | 넣는 곳 | 넣을 태그 |
|---|---|---|
| 히어로 | `.hero-media` 안 `.hero-art` **앞** | `<video autoplay muted loop playsinline poster="...">` 또는 `<img>` |
| 사업영역 카드 | `.biz-media` 안 `<svg>` **앞** | `<img src="assets/images/biz-*.jpg" alt="">` |

## 작동 원리 애니메이션 (경쟁사 magachem.com 참고 요청)
※ magachem.com은 WAF 봇 차단으로 직접 열람 실패 (headless·WebFetch 모두 차단).
   사용자가 말한 "기술 설명 영상"의 형식은 미확인 상태.

영상 파일(mp4) 대신 **SVG + CSS/JS 단계 애니메이션**으로 구현.
이유: 촬영·3D 렌더링 비용 없음 / 화질 무손실 / 문구·수치 수정 즉시 가능 /
용량 수 KB (영상은 수 MB) / 다크 톤 그래픽 언어와 일관.

- `#firestop` — 평상시 → 화재 발생 → 발포·팽창 → 차단 완료
- `#shutter` — 평상시 → 화재 감지 → 자동 폐쇄 → 구획 완성

구조: `.anim[data-step]` 안에 `.anim-stage`(SVG) + `.anim-steps`(4단계 버튼).
JS(`main.js`)가 4.2초마다 단계를 넘기고, `data-on="2,3"` 속성이 붙은 요소에
`.on` 클래스를 토글. 버튼 클릭 시 자동 재생 중단 후 해당 단계 고정.
IntersectionObserver로 화면 안에 있을 때만 재생, `prefers-reduced-motion`이면
자동 재생 없이 최종 단계 표시.

컬러: 기존 모노톤 + 파랑에 **화염 앰버 `#ff8a3c`** 추가 — 화염/열기류/탄화층에만 사용.

단계 수·문구를 바꾸려면 `index.html`의 `.anim-steps` 항목과
SVG 요소의 `data-on` 값만 맞추면 됨. 재생 간격은 `main.js`의 `STEP_MS`.
